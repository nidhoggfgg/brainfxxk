# brianfxxk
a brainfuck interpreter made by shell
首先你得懂brainfuck，不懂的可以看我的小白教程
→http://nidhoggfgg.gitee.io/myblog/2020/01/01/brainfuck/
它是支持完整的八条brainfuck指令的，并且新增一个~用于sleep 0.1
ps.和c写的相比，它是相当的慢的
使用方法如下
```
-f <文件>解释文件
-s <字符串>解释字符串
-c <导入config文件>
-h 打印说明文字
```
另外它可以使用除了brainfuck定义的字符编程
比如
```
$ bash my.sh -s "00000000 6 2 000000000 3 1   7 2 046170000 6 2 00000000 3 1   7 240000006200317240004000000041111111111111111146170000 6 2 00000000 3 1   7 24 11 6 2000 3 1   7 214111111111140000004"
I LOVE YOU$
```
这是因为它默认如下预翻译
0 +
1 -
2 >
3 <
4 .
5 ,
6 [
7 ]
8 ~
同时这个预翻译你是可以干预的，你只需要用-c传入即可
这个config编写格式如下
```
point=  #初始指针位置,默认为150,栈帧为301
offset=  #起始翻译位置,默认为0
s=  #将对应字符为替换+,下同
s_=  #-
s__=  #>
s___=  #<
s____=  #.
s_____=  #,
s______=  #[
s_______=  #]
s________=  #~
code=  #要翻译的代码ps.会覆盖-f和-s传入的code
```
当然，它的每一项都是非必须的，举个简单的config例子
```
s='='
```
